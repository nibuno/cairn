# Cairn Design System

- Version: 0.2.0
- Status: working proposal
- Date: 2026-08-14
- Scope: Cairn の記録・振り返り画面

調査根拠は [cairn-design-research.md](./cairn-design-research.md)、現在の画面実験は [cairn-design-preview.html](../design/cairn-design-preview.html) に分離する。この文書は採用するルールだけを扱い、HTMLの一時的な表現を自動的にデザインシステムへ昇格させない。

## 1. プロダクトの前提

Cairn は、自分の学習や活動を小さな単位で記録し、後から振り返るための個人向けアプリとする。

- 最頻操作: 今日の項目を1操作で記録する
- 次に重要な情報: 今日の未記録数、今週の回数、最近の履歴
- 評価しないもの: 休息、中断、再開、頻度変更
- 初期対象: 日本語、モバイルを含む日常利用

実際のアプリ本体と利用者調査が取得できたら、この前提を更新する。

## 2. 設計原則

### 2.1 今日の操作を最優先にする

ホーム画面では、日付、今日の項目、記録操作を最初に走査できるようにする。履歴や週次集計は、主操作と競合しない強さにする。

### 2.2 進捗を示し、評価しない

実施回数、時間、内容を事実として示す。未達を人格評価に結び付けず、罪悪感を使う文言を置かない。

### 2.3 再開を正式な成功として扱う

連続日数だけを成功指標にしない。累計、直近7日、再開を併記し、「今日は休む」「頻度を変更」を正式な操作として扱う。

### 2.4 装飾には役割を求める

色は操作、選択、状態、データ識別に限定する。影は重なりを示す場合だけに使う。グルーピングは見出し、余白、罫線、必要最小限の面で行う。

## 3. 情報設計

### ナビゲーション

| ラベル | 役割 |
|---|---|
| 今日 | 今日の項目を記録する |
| 記録 | 過去の履歴を確認・編集する |
| 振り返り | 期間集計と変化を見る |
| 設定 | 項目、頻度、通知、データを管理する |

「項目を追加」は今日画面で頻繁に使う場合のみヘッダーへ置く。それ以外では設定内へ戻す。

### 今日画面の優先順位

1. 日付と今日の記録数
2. 未記録の項目と `記録する`
3. 記録済みの項目
トップページには今週の詳細と最近の履歴を置かない。それぞれ `振り返り` と `記録` に置き、ナビゲーションとの重複を避ける。

大きな KPI ヒーロー、ランキング、称号、説明目的だけのイラストは置かない。

## 4. ビジュアル基盤

現在のHTML実験は Tailwind CSS v4 の標準ユーティリティだけを使用する。独自CSS、インラインstyle、独自テーマは、方向性が決まるまで追加しない。

### カラーの役割

| 役割 | Tailwind | 用途 |
|---|---|---|
| Page | `stone-50` | ページ背景 |
| Surface | `white` | 今日の記録をまとめる面 |
| Text | `stone-800 / 900` | 本文、見出し |
| Muted text | `stone-500` | 日付、補助情報。`stone-400` は非活性・装飾だけ |
| Border | `stone-100 / 200` | 区切り、面の境界 |
| Action | `amber-300 / 400` | 未記録の操作、現在日 |
| Focus | `amber-500` | キーボードフォーカス |

黄色は楽しさを担う装飾色ではなく、今すぐ操作できる対象と現在位置を示す。成功、警告、カテゴリ色には転用しない。

### タイポグラフィ

OS標準フォントを使う。本文は原則16px以上、補助情報は14pxまでとする。

| Role | Tailwind | 用途 |
|---|---|---|
| Page title | `text-3xl font-semibold` | 今日、記録などの画面名 |
| Section title | `font-semibold` | 今日の記録、今週、最近の記録 |
| Body | default / `font-medium` | 項目名、本文 |
| Meta | `text-sm text-stone-500` | 日付、目安、継続日数 |

### 余白と幅

- 基準: Tailwind の 4px spacing scale
- モバイル左右: `px-4`
- 640px以上: `px-6`
- 最大幅: `max-w-6xl`
- 主領域と補助領域: desktop で 2:1、tablet以下では1列
- タップ対象: 44 × 44px以上

### 形と面

- ボタン: `rounded-md`
- 機能単位の面: `rounded-lg border`
- 一覧内部: 追加のカードを作らず `divide-y`
- shadow: dialog、popover、drag中だけ
- pill: segmented controlなど、形が操作方法を示す場合だけ

## 5. コンポーネント

### 5.1 App header

ブランド、主要4ナビゲーション、必要な場合だけ `項目を追加` を置く。現在位置は文字色だけでなく下線でも示す。モバイルではブランド・追加操作の下へナビゲーションを送る。

### 5.2 Record list

1行に次を置く。

- 項目名
- 目安時間と継続情報
- 記録操作

記録状態:

- 未記録: 黄色の `記録する`
- 記録済み: neutral の `✓ 記録済み`
- 送信中: `記録中…`、重複操作を無効化
- 失敗: 行内に `記録できませんでした。再試行`

状態は色だけで示さず、文言と `aria-pressed` を併用する。

### 5.3 Week summary（振り返り画面）

今週の目標回数と、曜日別の件数を表示する。今日だけ背景を変え、曜日ラベルも併記する。初期表示ではグラフにせず、7日分を直接読める形式を使う。

### 5.4 Recent records（記録画面）

日時、項目、時間を新しい順に最大3件表示する。全件は `すべて見る` から記録画面へ移動する。カード内カードにはしない。

### 5.5 Button

種類は `primary / secondary / danger / text`。

- primary: 現在の主要操作。1セクションに原則1種類
- secondary: 取消や補助操作
- danger: 削除など不可逆操作
- text: 遷移や優先度の低い操作

default、hover、focus-visible、pressed、disabled、loading を定義する。

### 5.6 Empty / loading / error

- Empty: 空である事実と、最初の項目を作る操作
- Loading: 最終レイアウトに近い高さを確保する
- Error: 失敗対象、保持された入力、再試行方法
- Offline: ローカル保存済みか未保存かを明示する

## 6. ライティング

使う:

- `記録する`
- `✓ 記録済み`
- `今日は休む`
- `頻度を変更`
- `8月12日以来の記録です`

使わない:

- `連続記録が途切れます。本当に休みますか？`
- `みんなは続けています`
- `あと少しなのに諦めますか？`
- `レベルアップ`
- `次の一歩をサポートします`

見出しの下に説明文を機械的に置かない。操作名は直接的な動詞にする。

## 7. アクセシビリティ受入条件

- 本文とラベルは背景に対して4.5:1以上
- 非テキストUI、境界、フォーカスは隣接色に対して3:1以上
- 320px幅でページ全体の水平スクロールを起こさない
- 200%拡大で主要操作と内容を失わない
- キーボードだけで全操作が可能
- focus-visibleを表示する
- 状態とデータを色だけで伝えない
- 見出し、landmark、label、name/role/valueを適切にする
- touch targetは原則44px以上

## 8. 検証対象

- Viewport: 1440×900、768px、375px、320px
- State: default、recorded、全件記録、loading、empty、error
- Input: mouse、touch、keyboard
- Automated: HTML、JavaScript、axe相当の検査

## 9. 現在の判断

- トップページは今日の記録だけに限定
- 最初の案にあったテーマ選択、KPIカード、棒グラフは不採用
- 積み石イラスト、不整形、複数の強い色は不採用
- 今週の詳細と最近の履歴は、専用画面と重複するためトップでは不採用
- 完全な無彩色一枚面は、情報のまとまりが弱いため不採用
- 現在は Tailwind 標準の stone + amber を検証中

ブランドカラー、独自フォント、独自モーションは未決定とし、現在のHTMLだけを根拠に固定しない。
